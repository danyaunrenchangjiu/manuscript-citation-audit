# Scholarly Citation Audit｜稿件引文审查

`manuscript-citation-audit` 是一个面向学术投稿的 Codex Skill。它以正式出版记录为依据，逐条核验文末参考文献，并按你选定的期刊指南或 GB/T 7714-2015 生成可直接使用的参考文献表。

## 为什么做这个 Skill

1. **AI 辅助写引言时，推荐的文献需要核实。** AI 可能给出查无实据的条目，也可能推荐真实且主题相关的论文，但论文的研究对象、方法或结论不足以支撑稿件中的具体论断。
2. **用 Zotero 插入引文后，仍可能需要手动返工。** 导入时一旦漏掉作者、卷期、页码或文章号，套用样式后这些缺漏仍会留在参考文献表里。遇到样式库没有覆盖的目标期刊，或现有样式与期刊最新投稿指南存在差异时，还得回查作者指南并逐条调整。
3. **每次投稿前都要重复检查细节。** 作者顺序、正式刊载年份、在线优先发表状态、合期号、DOI 和不同类型文献的写法，都容易在最后一轮检查中遗漏。

将这些重复工作整理成一个可复用的流程。先查正式出版来源，核对书目信息和证据，再按选定规范生成条目，最后交付审查报告和修正版书目。

## 目前能做什么

- **核实文献与书目信息**。优先查出版社页面和正式刊载版本，必要时通过 DOI 登记记录或官方机构目录补证。逐位核对完整作者名单和顺序，并检查题名、刊名、出版年份、卷期、页码、文章号和 DOI。证据不足的事实会标明待核。
- **判断原文能否支撑稿件论断**。提供稿件时，在本地对照相关论断与被引原文，记录支持程度，并注明判断依据来自全文、摘要或其他公开材料。
- **按目标规范生成文末条目**。你只需选定目标期刊或国标，由 Skill 自行查适用条款。期刊论文、会议论文、图书和书中章节均先确认出版类型，再按相应规则著录。
- **生成 PDF 和修正版书目**。问题索引、参考文献分布分别排在独立页面，后续每条文献独占一页。索引与详情支持双向跳转。普通排版导出 UTF-8 纯文本 `.txt`，LaTeX 排版导出 BibTeX `.bib`。修正范围限于文末参考文献表。
- **可选 Codex 与 DeepSeek 交叉核验**。经你授权后，DeepSeek 仅接收公开书目信息、出版记录和必要的规范节选。报告并排展示两方判定，并汇总一致意见与分歧。最终依据为正式出版记录和所选著录规范。

## 如何使用

1. 在 Codex 中附上稿件、稿件片段或文末参考文献表，然后调用 `$manuscript-citation-audit`。
2. 在开始页输入目标期刊网址，或选择 **GB/T 7714-2015**。再选择是否用于 LaTeX 排版，以及仅 Codex 或 DeepSeek + Codex。
3. 阅读 PDF 首页的问题索引，点击条目查看依据，确认后将导出的参考文献表用于稿件。
